# 検出器情報のマッピング

実際の検出器情報の解析においては、どの読み出し回路のどのチャンネルが、解析者が思う検出器に対応しているかということが重要になります。
例えば、左右読み出しのシンチレータにおいて、1枚目のTDCの 0ch, 1ch がそれぞれ左、右に対応するということがどこかで定義されており、
その対応関係を解析コードで使って、左右を組みあせた情報に加工するという流れになることがほとんどです。

artemis ではバイナリデータから読み込んだデータを一旦回路単位のデータ (segmented data) の配列にまとめたあと、
プロセッサーが取り扱う操作ごとのデータ (categorized data) に対応付けるということをやることが多いです。（もちろんご自身のプロセッサーを書いて全く別の実装をすることも可能です。）
これを検出器要素と見なす場合もあり、さらにデータをまとめ上げて検出器のデータをつくるというふうに組み上げていきます。
最初の回路単位のデータを操作ごとのデータに対応付けるプロセッサは art::TMappingProcessor です。イベントストアのあとに呼ばれることが多いです。
次に検出器要素のデータへの対応づけは様々なプロセッサにわかれていますが、art::TRawDataMappingProcessor や、art::TTimingChargeMappingProcessor などがあります。
